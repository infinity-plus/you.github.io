Yes, on Android Chrome you may be able to launch the native camera app from a web link using an Android intent:// URL, because Chrome supports Android Intents from web pages. Android itself also supports camera launch intents such as android.media.action.IMAGE_CAPTURE for opening the camera app. What works A web page or link can try an Android intent like this: text intent://scan/#Intent;action=android.media.action.IMAGE_CAPTURE;end That pattern uses Chrome’s Android Intent support, and the action corresponds to the system camera capture intent documented by Android. In practice, it is Android-specific and browser-specific, so it is not something you can count on in Instagram’s in-app browser or on iPhones. Main limitation Even if the intent opens the camera app, the browser does not get a usable result back the way a native Android app can with startActivityForResult; for web use, it is basically just a handoff to the camera app. That means it can open the app, but it is not a reliable way to control the camera flow from a prank webpage or DM.
